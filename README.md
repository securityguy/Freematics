# Origin

This repo was originally a fork of [the original Freematics code. ](https://github.com/stanleyhuangyc/Freematics)

With PRs open since 2021, it does not appear that the upstream is accepting contributions.

# Status

The scope of this repo has been narrowed to firmware for the ESP32-based Freematics ONE+.

Several features have been added to address issues and improve compatibility with Traccar.
